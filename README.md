# CHB Form - ระบบกรอกแบบฟอร์ม Paperless สำหรับคนงาน

แอป Android สำหรับกรอกและสร้าง PDF แบบฟอร์มที่เกี่ยวข้องกับโครงการก่อสร้าง

## เทมเพลตที่รองรับ

| เทมเพลต | คำอธิบาย |
|---------|----------|
| **อบรม CHB** | แบบฟอร์มลงทะเบียนหลักสูตรความปลอดภัยและพื้นที่ปฏิบัติงาน |
| **ห้องพัก** | แบบคำร้องขออนุญาตเปิดห้องพักคนงาน (Christiani & Nielsen - COCONUT 1) |

## คุณสมบัติหลัก

- เลือกเทมเพลตได้ก่อนเริ่มกรอก
- ถ่ายรูปบัตรประชาชน + OCR ภาษาไทย
- เซ็นชื่อดิจิทัล
- สร้าง PDF พร้อมฟอนต์ Sarabun ฝังในตัว
- บันทึกข้อมูลหลายรายการ + นำเข้า/ส่งออก JSON
- ระบบโปรไฟล์เติมข้อมูลอัตโนมัติ

## สถานะการพัฒนา (อัปเดตล่าสุด)

### โครงสร้างพื้นฐาน Multi-Template (เสร็จแล้ว)
- `TemplateType.kt` — ระบบเลือกเทมเพลต
- `DormSpec.kt` — พิกัดเลย์เอาต์แบบฟอร์มห้องพัก
- `DormFormData.kt` — โครงสร้างข้อมูลแบบฟอร์มห้องพัก
- `TemplateStore.kt` — ระบบจัดเก็บแยกตามเทมเพลต + หลายรายการ + JSON

### งานถัดไป
- เชื่อม ViewModel และ UI ให้เลือกเทมเพลตได้
- สร้างหน้ากรอกสำหรับแบบฟอร์มห้องพัก
- ปรับปรุงฟอนต์ PDF และ UI/UX ให้เป็นมืออาชีพ
- ขยาย OCR ให้ครอบคลุมมากขึ้น
- รองรับนำเข้า JSON หลายชุดพร้อม Dropdown

## วิธี Build

```bash
./gradlew assembleDebug
```

## หมายเหตุ

แอปนี้พัฒนาเพื่อแจกจ่ายให้คนงานใช้จริงในรูปแบบ Paperless  
รองรับการขยายเทมเพลตเพิ่มเติมในอนาคต
