# CHB Form — นำเข้า PDF แล้วกรอก / สร้างใหม่

แอป Android สำหรับนำเข้า PDF แบบฟอร์ม ตรวจจับฟิลด์ (ถ้ามี) **เพิ่ม/ลบฟิลด์เองได้** กรอกข้อมูล แล้วสร้าง PDF

## โฟลว์การใช้งาน

1. **เลือกไฟล์ PDF**
2. ระบบวิเคราะห์ข้อความ / เส้น / กรอบ / AcroForm
3. **ไปหน้ากรอก** — แม้ตรวจไม่พบฟิลด์ก็เข้าได้
4. **เพิ่มฟิลด์ / ลบฟิลด์ / แก้ชื่อ** ตามต้องการ
5. กรอกข้อมูล (หลายชุดได้) → **สร้าง PDF** → แชร์

## จุดที่แก้แล้ว (สำคัญ)

| ปัญหาเดิม | แก้ไข |
|-----------|--------|
| ตรวจไม่พบฟิลด์แล้วไปต่อไม่ได้ | ไปต่อได้ แล้วเพิ่มฟิลด์เอง |
| คำเตือนนำเข้าบล็อกการสร้าง PDF | บล็อกเฉพาะฟิลด์บังคับว่าง |
| ลบ/เพิ่มฟิลด์ไม่ได้ | มีปุ่มเพิ่มฟิลด์ + ลบต่อแถว |
