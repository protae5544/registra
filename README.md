# CHB Form — ระบบกรอกแบบฟอร์ม Paperless จาก PDF

แอป Android สำหรับ**นำเข้า PDF แบบฟอร์มใดก็ได้** ตรวจจับฟิลด์อัตโนมัติ กรอกข้อมูล แล้วสร้าง PDF ใหม่ พร้อมฟอนต์ Sarabun

## แนวคิดหลัก

| ขั้นตอน | คำอธิบาย |
|---------|----------|
| **1. นำเข้า PDF** | เลือกไฟล์ PDF (AcroForm หรือวาดด้วยเส้น/กรอบ) |
| **2. วิเคราะห์** | สกัดข้อความ เส้น กรอบ ฟิลด์ + แสดงคำเตือนถ้าไม่ครบ |
| **3. กรอก / ตรวจ** | แก้ฟิลด์ อนุมัติฟิลด์ เติมข้อมูล JSON ได้ |
| **4. สร้าง PDF** | เรนเดอร์ตามพิกัดที่ตรวจได้ แชร์ไฟล์ได้ทันที |

ไม่ผูกกับแบบฟอร์มฮาร์ดโค้ด (อบรม / ห้องพัก) อีกต่อไป — ยืดหยุ่นกับฟอร์มโครงการใดก็ได้

## คุณสมบัติ

- นำเข้า PDF → ตรวจจับฟิลด์อัตโนมัติ
- รองรับ AcroForm และฟอร์มที่วาดด้วยเส้น/กรอบ
- คำเตือนเมื่อฟิลด์ไม่ครบหรือไม่ชัดเจน
- กรอกหลายรายการ (records) + นำเข้า JSON
- สร้าง PDF พร้อมฟอนต์ Sarabun ฝังในตัว
- แชร์ไฟล์หลังสร้างสำเร็จ

## วิธี Build

```bash
./gradlew assembleDebug
```

## หมายเหตุ

แอปนี้พัฒนาเพื่อแจกจ่ายให้คนงานใช้จริงในรูปแบบ Paperless  
โฟลว์หลักคือการนำเข้า PDF ฟอร์มจากโครงการ แล้วกรอกและสร้างเอกสารใหม่
