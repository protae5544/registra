# CHB Form — นำเข้า PDF / ภาพ แล้วกรอก

แอป Android สำหรับนำเข้าแบบฟอร์มจาก **PDF หรือไฟล์ภาพ** ตรวจจับฟิลด์ (ถ้ามี) **เพิ่ม/ลบฟิลด์เองได้** กรอกข้อมูล แล้วสร้าง PDF

## โฟลว์การใช้งาน

1. **เลือกไฟล์ PDF** หรือ **แนบไฟล์ภาพเป็นพื้นหลัง** (jpg / png / webp)
2. ถ้าเป็น PDF ระบบวิเคราะห์ข้อความ / เส้น / กรอบ / AcroForm และแคปหน้าเป็นภาพเก็บไว้
3. **ไปหน้ากรอก** — แม้ตรวจไม่พบฟิลด์ก็เข้าได้
4. **เพิ่มฟิลด์ / ลบฟิลด์ / แก้ชื่อ** ตามต้องการ
5. เลือกพื้นหลัง:
   - **พื้น PDF** — ใช้ไฟล์ต้นฉบับ
   - **พื้นภาพ** — ใช้ภาพที่แคป/แนบ แล้ว normalize ตามขนาดกระดาษที่ตั้ง (A4 / A5 / ต้นฉบับ)
   - **เฉพาะข้อมูล** — ไม่วาดพื้น
6. กรอกข้อมูล (หลายชุดได้) → **สร้าง PDF** → แชร์

## พื้นหลัง

| โหมด | พฤติกรรม |
|------|----------|
| พื้น PDF | raster หน้าแรกของ PDF ต้นฉบับ แล้ววางทับด้วยข้อมูลที่กรอก |
| พื้นภาพ | ถ้าไม่ใช้ PDF เป็นพื้น จะแคปเป็น JPEG ตามขนาดที่ set แล้ว contain/normalize ไม่ยืดภาพ — แนบ jpg/png แทนได้ |
| เฉพาะข้อมูล | วาดเฉพาะค่าที่กรอก บนหน้าว่าง |

## จุดที่แก้แล้ว (สำคัญ)

| ปัญหาเดิม | แก้ไข |
|-----------|--------|
| ตรวจไม่พบฟิลด์แล้วไปต่อไม่ได้ | ไปต่อได้ แล้วเพิ่มฟิลด์เอง |
| คำเตือนนำเข้าบล็อกการสร้าง PDF | บล็อกเฉพาะฟิลด์บังคับว่าง |
| ลบ/เพิ่มฟิลด์ไม่ได้ | มีปุ่มเพิ่มฟิลด์ + ลบต่อแถว |
| พื้นได้แค่ PDF | แคปเป็นภาพตามขนาดที่เลือก + แนบไฟล์ภาพได้ |

## ข้อควรระวังเรื่องวันเวลา (stamp)

ชิ้นงานชนิด **วันเวลา** ค่าวันที่ถูกฝังอยู่ในเทมเพลต แต่จะถูก**คำนวณใหม่เป็นเวลาปัจจุบันทุกครั้งที่เปิดไฟล์หรือพิมพ์**

ถ้าเอกสารนั้นต้องคงวันที่เดิมเสมอ (เช่น กรอกย้อนหลัง หรือพิมพ์ซ้ำเดิม) ให้กด **“ตรึงค่านี้ไว้”** ในแผงตั้งค่า ค่าจะถูกจับเป็นข้อความคงที่และไม่ขยับอีก
(ไม่ตรึงไว้ = วันที่จะเดินไปเงียบ ๆ โดยไม่มีอะไรเตือน)
