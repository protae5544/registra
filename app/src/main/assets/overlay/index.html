🏷 ดูรายชื่อ keyที่ใช้ในงานนี้
⚙️ ตั้งค่าการส่งออกฝังฟอนต์ · ความละเอียด PNG
❓ วิธีใช้งานทีละขั้น

วิธีใช้งาน 3 ขั้น

  1. วางพื้น — เมนูเพิ่มเติม → พื้นหลังเอกสาร แนบภาพหรือ PDF (เลือกได้หลายไฟล์ = หลายหน้า)
  2. ประทับชิ้นงาน — แถบบนกด + ข้อความ / + รูป / + QR / + วันเวลา แล้วลากวาง · ลากจุดกลมมุมเพื่อย่อ/ขยาย · ตั้งผูกกับ key ของข้อมูลที่แผงขวา
  3. ส่งออก — + นำเข้าข้อมูล JSON (ได้หลายไฟล์) → ปุ่ม PDF ทุกหน้า หรือแท็บ "พิมพ์" เพื่อแยกไฟล์/ตั้งชื่อ/ลำดับ

งานถูกเซฟอัตโนมัติเป็น draft ตลอด ถ้าออกไปแล้วกลับมา จะมีแถบ "กู้คืน" ขึ้นให้กดเมื่อเปิดใหม่ทันที
ชิ้นงาน "วันเวลา" — ไม่ตรึงจะคำนวณใหม่ทุกครั้งที่เปิดไฟล์/พิมพ์ กด “ตรึงค่านี้ไว้” เพื่อล็อกวันที่เดิม
